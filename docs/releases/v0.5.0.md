# Clipboard Remix 0.5.0 — prerelease

A native clipboard manager for text and screenshots on Apple Silicon Macs. This prerelease is intended for early testing; broad macOS/hardware compatibility is not yet established.

## Install

Download the application ZIP and optional SHA-256 checksum from the release Assets, unzip, and move **Clipboard Remix.app** to **Applications** or **~/Applications**. Do not use GitHub’s source-code ZIP as the application download.

Open the app, then click its menu-bar clipboard icon or press **Option-Command-V**. Capture starts quietly. Click-to-paste requires Accessibility permission; copy-only actions do not.

## Included features

- Remembered palette position/size with off-screen recovery.
- Opt-in Launch at Login from standard Applications locations.
- Pinned text/image favorites protected from automatic retention cleanup.
- Timed and indefinite capture pause.
- Brief copy/paste-event feedback.
- Native PNG preview dragging into documents and browser upload targets.
- Exact text and normalized-image deduplication.

## Portability changes

Login launch no longer depends on a developer-specific external-drive path. History and preview/drag snapshots use your account’s Application Support directory. Image drag snapshots remain available through the transfer and receive a seven-day cleanup grace after release.

If moving an older registered copy, disable Launch at Login in that copy first. Quit it, install/open this version, and enable Launch at Login again if desired. Installation never enables it automatically.

## Verification and limitations

The release candidate passes 14 automated core check groups plus native palette/model checks on one Apple Silicon Mac. Earlier manual checks confirmed TextEdit and Comet + ChatGPT image dragging, cancellation, favorites, and corrected palette reopening.

Only same-Mac verification is available. Another Mac, a fresh user account, the declared macOS 14 minimum, real sleep/wake and logout/login sessions, and physical multi-display disconnection have not all been verified. Feedback from early testers is welcome.

Signing, notarization, archive, and installation results will be recorded in this draft before publication. Do not treat a draft as an available public download.

Clipboard history is local and unencrypted. Clipboard Remix does not sync or automatically upload it. Dropping an image onto a website hands it to that website. Clear History removes favorites too; independent drag snapshots expire separately.

Report bugs with app/build, macOS version, destination app, and benign reproduction steps. Do not attach private clipboard history.
